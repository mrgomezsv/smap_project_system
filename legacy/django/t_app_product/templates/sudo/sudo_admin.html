Capa de Seguridad Activa: Firebase Auth

Todas las peticiones (excepto catálogos públicos) requieren el encabezado: Authorization: Bearer <ID_TOKEN>. El servidor valida automáticamente la identidad con el SDK de Firebase.

Gestión de Productos
GET /api/products/

Lista completa de productos.

curl -X GET http://127.0.0.1:8000/api/products/
GET /api/products/category/{id}/
